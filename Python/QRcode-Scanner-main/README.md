# QRcode-Scanner
Simple practice code I did to learn how pyzbar, opencv functions with the help of the article on https://towardsdatascience.com/building-a-barcode-qr-code-reader-using-python-360e22dfb6e5


Press the "Esc" key to close the camera window and the result will be printed on the terminal and in a separate .txt file in the same directory.
